# @onegrid/webgpu

WebGPU compute kernels for oneGrid: GPU-accelerated reductions, filters, and sorts over typed-array columns. Falls back to CPU when WebGPU is unavailable.

Part of [oneGrid](https://github.com/CelestialBrain/onegrid) — a free, MIT-licensed, framework-agnostic
data grid. See the [monorepo README](https://github.com/CelestialBrain/onegrid#readme) for the full
package map, architecture, and roadmap.

## Install

```sh
npm install @onegrid/webgpu
```

## Documentation

This package is documented in the [oneGrid repository](https://github.com/CelestialBrain/onegrid/tree/main/packages/webgpu).
The public API surface is tracked in
[`docs/api`](https://github.com/CelestialBrain/onegrid/tree/main/docs/api).
