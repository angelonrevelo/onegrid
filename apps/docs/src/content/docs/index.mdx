## What oneGrid is

A single MIT-licensed grid that consolidates what real applications need at
scale into one coherent stack — no per-seat licensing, no feature gates.

<CardGrid stagger>
  <Card title="Canvas-first rendering" icon="seti:default">
    Renders millions of rows on a canvas with row + column virtualization,
    backed by a DOM accessibility shadow (WAI-ARIA 1.2 grid semantics) and
    DOM overlays for editors and detail panels.
  </Card>
  <Card title="Spreadsheet-class formulas" icon="seti:math">
    An Excel-compatible formula engine — parser, dependency graph with range
    nodes, demand-driven recompute, hundreds of built-in functions, and
    OOXML (`.xlsx`) round-trip.
  </Card>
  <Card title="Databases + ORMs, first-class" icon="seti:db">
    Server-side row model with cursor pagination and a real-time row-diff
    protocol, plus adapters for Postgres, MySQL, SQLite, ClickHouse, DuckDB,
    Mongo — and ORM integrations.
  </Card>
  <Card title="Framework-agnostic" icon="seti:html">
    A small framework-agnostic core with idiomatic adapters for React, Vue,
    Svelte, Solid, Angular, and Web Components — plus a headless lifecycle
    contract.
  </Card>
</CardGrid>

## Install

```sh
npm install @onegrid/core
# framework adapter, e.g. React:
npm install @onegrid/react
```

See [Getting started](/getting-started/) for a first grid, or the
[package map](/packages/) for the full surface.
